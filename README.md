# Hotel Reservation App (Lab 6)

Flutter prototype for Lab Exercise 6.1 implementing Material 3 input, selection, dialog, bottom sheet, and expansion panel widgets.

## Screens

- `lib/login_page.dart`: Sign in screen with form validation
- `lib/signup_page.dart`: Account registration form
- `lib/dashboard_page.dart`: Booking form (DatePicker, TimePicker, SegmentedButton, Slider, RadioListTile, CheckboxListTile, SwitchListTile, AlertDialog, SnackBar)
- `lib/room_list_page.dart`: Room catalog with budget Slider filter, Modal Bottom Sheet details, and FAQ ExpansionTile list

## Run Tests & Coverage

```bash
flutter test --coverage
```
